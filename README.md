# BEP3.0

**BEP3.0** is an electronics interface for classic BMW K-series motorcycles.

It was developed to make replacing the original instrument cluster ("Brotbox")
with an aftermarket speedometer easier while keeping the original wiring loom
as intact and reversible as possible.

This repository contains the **production and manufacturing files** for the
BEP3.0.

## Supported motorcycles

The BEP3.0 was designed for the classic BMW K-series, including:

- BMW K75
- BMW K100
- BMW K1
- BMW K1100

Compatibility with a particular aftermarket instrument depends on the signals
and inputs supported by that instrument.

## What is in this repository?

The repository contains the files used to produce the BEP3.0 hardware, including
PCB/manufacturing data and related production files.

The files are published so that the project can be studied, preserved, repaired
and rebuilt by private users.
